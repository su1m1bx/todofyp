# Todo List

**해야 할 일을, 눈에 보이는 곳에.**

다른 작업을 하면서도 다음 할 일을 확인할 수 있도록 만든 macOS 메뉴 막대 투두 앱입니다. 작은 플로팅 창, macOS에 어울리는 유리 소재 UI, 계정 없이 사용하는 로컬 저장에 집중했습니다.

## 이런 점이 좋아요

- **중요한 일부터 하나씩** — Enter로 빠르게 추가하고, 드래그나 키보드로 우선순위를 바꿔보세요. 목록이 길어져도 창 대신 목록만 스크롤됩니다.
- **가볍게 띄우고, 필요하면 숨기기** — 메뉴 막대에서 표시/숨김을 전환합니다. Dock에 최소화 창을 쌓지 않습니다.
- **실수해도 괜찮게** — 완료와 삭제는 별개입니다. 삭제한 항목은 각각 5초 동안 실행 취소할 수 있고, 재실행해도 남은 유예 시간이 유지됩니다.
- **할 일에 맥락 더하기** — 선택적 기한, 여러 카테고리, 카테고리 필터와 굵게·기울임·밑줄을 지원하는 상세 메모를 제공합니다.
- **내 Mac에 어울리게** — 시스템/라이트/다크 모드, 배경 색상·이미지, 완료 체크 색상을 설정할 수 있습니다. 기본 화면 모드는 Mac의 시스템 설정을 따릅니다.
- **계정도 서버도 없이** — 기본 기능은 오프라인으로 작동합니다. 분석 SDK, 클라우드 동기화, 백그라운드 네트워크 전송을 사용하지 않습니다.

## 사용 환경과 현재 상태

- **macOS 26 이상, Apple Silicon** — 현재 제공하는 DMG의 앱은 arm64 빌드입니다.
- macOS 26.2 / Apple Silicon에서 빌드 및 자체 실행 검사를 수행했습니다. Intel은 교차 빌드만 확인했으며 실행 지원은 검증하지 않았습니다.
- 전체 화면 앱, 여러 Spaces, Stage Manager와 외부 모니터 조합의 표시·입력은 아직 전체 실기기 검증을 마치지 않았습니다. 모든 화면 위에 표시되는 것을 보장하지 않으며, 잠금 화면·시스템 보안 UI는 보장 범위가 아닙니다.
- **현재 패키지는 사전 공개/테스트용이며 Developer ID 서명·Apple 공증이 완료되지 않았습니다.** 로컬 ad-hoc 서명은 Apple의 개발자 신원 확인이나 안전성 승인을 뜻하지 않습니다. 호환성 인수와 공증된 정식 배포는 아직 완료되지 않았습니다.

## 다운로드 및 설치

1. 이 GitHub 저장소의 **Releases**에서 사용할 버전의 **Assets**를 펼칩니다.
2. 첨부된 `.dmg` 파일을 내려받습니다. `Source code (zip)`은 설치 파일이 아닙니다.
3. DMG를 열고 **`Important Todo.app`을 `Applications` 폴더로 드래그**합니다.
4. DMG를 추출한 뒤, Finder의 **응용 프로그램**에서 앱을 실행합니다.

앱 파일 이름은 `Important Todo.app`, 목록 제목은 **Todo List**입니다. DMG 안에서 직접 실행하지 말고 먼저 응용 프로그램 폴더에 복사해 주세요.

### 처음 실행할 때 macOS가 차단한다면

공증되지 않은 앱이므로 macOS에서 개발자를 확인할 수 없다는 경고가 나타날 수 있습니다. **이 저장소의 Release에서 직접 받은 파일이며 출처를 신뢰할 때만** 아래 방법을 선택하세요. 제공된 SHA-256 체크섬이 있다면 먼저 확인하는 것을 권장합니다.

DMG와 `.sha256` 파일을 같은 폴더에 내려받았다면 해당 폴더에서 아래 명령으로 확인할 수 있습니다. `OK`가 나오지 않으면 설치를 중단하세요.

```sh
shasum -a 256 -c ImportantTodo-local.dmg.sha256
```

**방법 1 — 시스템 설정에서 해당 앱만 허용 (권장)**

1. 설치한 앱을 한 번 실행해 경고를 확인합니다.
2. **시스템 설정 → 개인정보 보호 및 보안 → 보안**으로 이동합니다.
3. 해당 앱에 대해 **확인 없이 열기(Open Anyway)**를 선택하고, 안내에 따라 인증한 뒤 다시 실행합니다.

표시 문구와 허용 여부는 macOS 버전·관리 정책에 따라 달라질 수 있습니다. 회사나 학교에서 관리하는 Mac이라면 관리자에게 문의하세요.

**방법 2 — 터미널에서 설치한 앱의 격리 속성만 제거**

방법 1을 사용할 수 없고 파일 출처를 확인했다면, 터미널에서 다음 명령을 실행합니다. 아래 경로에 설치했을 때만 그대로 사용하세요.

```sh
xattr -dr com.apple.quarantine "/Applications/Important Todo.app"
open "/Applications/Important Todo.app"
```

이 명령은 **지정한 앱 번들에 한해서** 다운로드 격리 속성을 제거합니다. 개발자 신원을 검증하거나 앱을 공증하는 명령은 아니며, 앱이 안전하다는 보장도 아닙니다. 실행 허용을 보장하지 않으므로 오류가 나면 경로·다운로드 출처를 다시 확인하세요.

**Gatekeeper 전체 비활성화, 전체 디스크 접근, 접근성 제어, 화면 녹화, 관리자 권한 부여는 필요하지 않습니다.** 명령의 대상을 홈 폴더나 `/Applications` 전체로 넓히지 마세요. 악성 코드 경고 또는 실제 파일 손상·서명 오류가 있으면 우회하지 말고 실행을 중단하고 공식 Release에서 다시 내려받으세요.

## 간단한 사용법

| 하고 싶은 일 | 방법 |
| --- | --- |
| 할 일 추가 | 입력 후 **Enter** |
| 순서 변경 | 다른 항목 앞으로 드래그, 또는 목록 선택 후 **⌥↑ / ⌥↓** |
| 상세 편집 | 제목 더블클릭, 상세 버튼, 또는 목록 선택 후 **Enter** |
| 메모 서식 | 텍스트 선택 후 **⌘B / ⌘I / ⌘U** 또는 서식 버튼 |
| 창 표시·숨김 | 메뉴 막대 아이콘 클릭 또는 창의 숨기기 버튼 |
| 설정·종료 | 메뉴 막대 아이콘 보조 클릭 |
| 아이콘이 보이지 않을 때 | Finder의 응용 프로그램에서 앱을 다시 실행해 기존 창 복구 |
| 화면 모드·카테고리 관리 | **설정 → 외형 / 카테고리** |

창 크기·위치와 할 일·설정은 재실행 후 복원됩니다. 로그인 시 시작은 기본 꺼짐이며 설정에서 직접 켤 수 있습니다. 날짜는 기한으로만 사용하며 알림·반복 일정·동기화는 제공하지 않습니다.

## 내 데이터는 어디에 저장되나요?

할 일, 메모, 설정과 선택한 배경 이미지 사본은 **앱 전용 샌드박스**에 저장됩니다.

```text
~/Library/Containers/dev.local.important-todo/Data/Library/Application Support/ImportantTodo/document.json
```

배경 이미지는 시스템 파일 선택기로 사용자가 직접 고른 **PNG/JPEG/HEIC, 10MiB·24메가픽셀 이하**만 가져옵니다. 사본만 저장하며 원본 파일은 수정하지 않습니다. 다른 앱의 데이터나 화면을 읽지 않습니다.

앱 삭제가 데이터 삭제를 의미하지는 않습니다. 백업이 필요하면 앱을 종료한 뒤 위 파일을 별도로 보관하세요. 할 일과 메모가 들어 있으므로 이 파일을 공개 저장소나 이슈에 올리지 마세요.

## 소스에서 빌드하기

macOS 26 이상과 해당 SDK를 지원하는 Swift 도구 체인이 필요합니다. 현재 검증 도구 체인은 **Swift 6.3.3 / macOS SDK 26.5**입니다. 외부 패키지 의존성은 없습니다.

```sh
swift test
bash scripts/build.sh
open "dist/Important Todo.app"
```

샌드박스 권한과 메뉴 막대 앱 설정이 적용되도록 `swift run` 대신 생성된 `.app` 번들을 사용하세요.

DMG 생성:

```sh
bash scripts/package.sh
```

출력은 `dist/Important Todo.app`과 `dist/ImportantTodo-local.dmg`입니다. 실행한 Mac의 아키텍처로 빌드하며 자동 universal 빌드는 아닙니다. 스크립트 기본값은 ad-hoc 서명입니다. `SIGNING_IDENTITY`로 별도 identity를 지정해도 공증·스테이플은 자동 수행되지 않습니다.

### 개발 검증

실행 중인 이 앱을 먼저 종료하세요.

```sh
swift test --filter RepositoryTests/testAppearanceSelectionSurvivesRestartForEveryMode
"dist/Important Todo.app/Contents/MacOS/ImportantTodo" --smoke-check
python3 scripts/check-relaunch.py
```

자체 실행 검사는 별도 임시 데이터로 저장·서식·창 상태를 검사하고, 재실행 검사는 이 앱의 기존 프로세스·창 복구를 확인합니다. 다른 앱 위 실제 표시, 전체 화면·Spaces·Stage Manager, VoiceOver와 깨끗한 Mac의 설치·Gatekeeper 검증을 대신하지 않습니다.

### GitHub에 배포하기

소스는 저장소에, 설치 파일은 **GitHub Release의 Assets**에 올립니다. `dist/`와 DMG는 소스 이력에서 제외됩니다.

1. 위 명령으로 테스트와 패키징을 수행하고, 배포할 Mac/OS에서 수동 인수 검사를 마칩니다.
2. `.app`을 DMG에서 응용 프로그램으로 복사해 설치·첫 실행·복구를 검사합니다. 다른 깨끗한 Mac의 다운로드/Gatekeeper 검증도 별도로 필요합니다.
3. 아래 명령으로 DMG 체크섬을 만들고, GitHub Release에 **DMG와 체크섬 파일**을 첨부합니다.

```sh
(cd dist && shasum -a 256 ImportantTodo-local.dmg > ImportantTodo-local.dmg.sha256)
```

Release 설명에는 **버전, 지원 OS·아키텍처, 실제 확인한 환경, 알려진 제약, Developer ID 서명·공증 여부**를 명시하세요. 미완료 검증이 남은 현재 빌드를 올린다면 **Pre-release**로 표시하고, 공증된 정식 배포본으로 소개하지 마세요.

`.gitignore`에 등록된 로컬 파일도 이미 커밋했거나 별도로 업로드한 경우에는 공개될 수 있습니다. 첫 공개 전에 `git status`와 업로드할 파일을 확인하고, 실제 토큰·서명 자격이 노출됐다면 파일 제거뿐 아니라 해당 자격도 폐기·교체해야 합니다.
